# TODO-01: CalendarView の選択枠・拡大廃止と「今日」の日付表示

- **ステータス**: 未着手
- **優先度**: 高（即効改善）
- **並列着手**: 可能（フロントエンド単体で完結し、他タスクと競合しません）

---

## 1. 背景と課題

モバイル端末でカレンダー表示（`CalendarView`）を利用する際、以下の 2 つの UI 上の問題が発生しています。

1. **選択・フォーカス時の白縁取りと拡大が余白を圧迫している**
   - 日付セル選択時に明るい外周リングと拡大アニメーションが適用されており、グリッドが前提としているセル間の余白を食い潰し、窮屈な見た目になっています。
   - ユーザー要望として、選択時・フォーカス時の表現は外枠の縁取りや拡大ではなく、**背景色・文字色などの色変化のみ**で表現したいという方針が確定しています。
2. **今日の日付が一見してわからない**
   - カレンダー上の日付セルに当日を示す装飾がないため、特に今日にライブ予定が入っていない日において、現在日がどのマスかを瞬時に判別できません。

---

## 2. 現行コードの問題箇所

対象ファイル: [`apps/web/src/components/CalendarView.tsx`](../apps/web/src/components/CalendarView.tsx)

1. **初期年月の取得だけで「今日」のセル判定をしていない（17-19行目）**
   - `const today = new Date();` を年月の初期値（`year`, `month`）にのみ使用しており、日付文字列（`YYYY-MM-DD`）としての当日比較を行っていません。
   - なお、当日文字列取得ユーティリティ `getTodayStr(nowDate = new Date())` が [`apps/web/src/utils/date.ts`](../apps/web/src/utils/date.ts) にすでに実装されています。

2. **選択・フォーカス時のクラスに `scale-105` と `ring-2` が含まれている（194-213行目）**
   - `cellTheme` の `planned.selected` / `attended.selected` / `default.selected` にそれぞれ以下のクラスが付与されています:
     - `scale-105`
     - `ring-2 ring-sky-200/90`（および `ring-emerald-200/90`, `ring-rose-200/90`）
   - `idle` 側にも `focus-visible:ring-2 focus-visible:ring-*-400` があり、フォーカス時にセル外周にリングが出ます。

3. **日付セルの描画構造（215-247行目）**
   - `hasLive` が `false` の日付は `'bg-stone-900/30 text-stone-600 cursor-default'` 固定となっており、`todayStr` との一致判定がありません。

---

## 3. 実装要件

1. **外周リングと拡大の完全撤去**
   - `CalendarView.tsx` の日付セルにおいて `scale-105` および `ring-2 ring-*-200/90`（`planned` / `attended` / `default` すべて）を削除すること。
   - 選択状態は塗りつぶし背景色（`bg-sky-500`, `bg-emerald-500`, `bg-rose-500`）と文字色（`text-stone-950 font-black`）など、セル内側・色変化のみで明確に表現すること。
   - フォーカス時の見た目も外側に張り出すリング（`focus-visible:ring-2`）を止め、余白を侵食しない背景色・文字色または内側の変化へ統一すること。
2. **今日の日付（「今日」）の視認性向上**
   - `getTodayStr()` を使い、各セルで `const isToday = dateStr === todayStr;` を判定すること。
   - `hasLive === true` の日でも `hasLive === false` の日でも、今日の日付であることが一目でわかるようにすること（例: 日付数字の下の控えめなアンダーバー / 小さな「今日」ラベルやアクセントドット / セル内側の強調色など）。
   - 「今日」表現を追加する際も、セルサイズ膨張や `ring-*` による隣接セルとの余白侵食を起こさず、既存の `min-h-[44px]` や 3 種類のライブ状態カラー（予定 `sky` / 参戦済み `emerald` / 未定 `rose`）および選択状態と干渉・誤認しない配色にすること。
