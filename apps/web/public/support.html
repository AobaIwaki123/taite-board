お問い合わせ

GitHub Issuesのサポート窓口を開く

不具合を報告する際は、次の情報を分かる範囲で記載してください。

  • iOSのバージョンと端末名
  • アプリのバージョン
  • 発生した画面と操作手順
  • 表示されたエラー内容

投稿には、氏名、住所、電話番号、認証情報などの個人情報を含めないでください。

スケジュール情報について

ライブ情報の訂正・追加も同じ窓口で受け付けます。出典URLや告知内容が分かる場合は、あわせて共有してください。
